# บทที่ 11: Loops, break/continue, Nested Loops

## แนวคิดหลัก (Concept)

บทที่แล้วเราเรียนวิธี "เลือกทาง" ด้วย if/else บทนี้จะเรียนวิธี "ทำซ้ำ" — **Loop (การวนซ้ำ)** คือกลไกที่สั่งให้กลุ่มคำสั่งทำงานซ้ำๆ โดยไม่ต้องเขียนโค้ดเดิมซ้ำหลายบรรทัด

- **for loop** — วนซ้ำตามจำนวนครั้งที่กำหนดไว้ล่วงหน้า หรือวนไล่ทีละสมาชิกของ collection (array, list) เหมาะเมื่อรู้ล่วงหน้าว่าจะวนกี่รอบหรือวนอะไร
- **while loop** — วนซ้ำ**ตราบใดที่**เงื่อนไข (boolean expression จากบทที่ 6) ยังเป็น True เหมาะเมื่อไม่รู้ล่วงหน้าว่าจะวนกี่รอบ ขึ้นอยู่กับเงื่อนไขที่เปลี่ยนแปลงระหว่างทาง
- **break** — หยุดการวนซ้ำทั้งหมดทันที ออกจาก loop เลย
- **continue** — ข้ามรอบปัจจุบัน กลับไปเริ่มรอบถัดไปของ loop ทันที (ไม่ทำคำสั่งที่เหลือในรอบนี้)
- **Nested Loop (loop ซ้อน loop)** — loop หนึ่งอยู่ข้างในอีก loop หนึ่ง ใช้เมื่อต้องประมวลผลข้อมูลหลายมิติ (เช่น ตาราง 2 มิติ)

## ทำไมต้องมีสิ่งนี้ (Why it exists)

- **Loop มีไว้แทนที่การเขียนโค้ดซ้ำๆ (เหมือน Function ในบทที่ 9 แต่แก้ปัญหาคนละแบบ)**: ถ้าต้องพิมพ์ตัวเลข 1 ถึง 1,000,000 การเขียน `print(1); print(2); ...` ทีละบรรทัดเป็นไปไม่ได้จริง Loop ทำให้เขียนตรรกะครั้งเดียวแล้วสั่งให้ทำซ้ำได้
- **for กับ while มีไว้ตอบโจทย์คนละสถานการณ์**: for เหมาะกับ "จำนวนรอบที่แน่นอน" (นับ 1-10, ไล่ทุกสมาชิกใน list) ส่วน while เหมาะกับ "ทำไปเรื่อยๆ จนกว่าเงื่อนไขจะเปลี่ยน" (เช่น รอ input จากผู้ใช้จนกว่าจะพิมพ์ "quit")
- **break/continue มีไว้ควบคุมการวนซ้ำอย่างละเอียดกว่าการพึ่งเงื่อนไขหลักอย่างเดียว**: บางครั้งต้องหยุดกลางทางทันทีเมื่อเจอเงื่อนไขพิเศษ (เช่น เจอค่าที่ต้องการแล้วไม่ต้องวนต่อ) หรือข้ามบางรอบไปโดยไม่หยุดทั้งหมด (เช่น ข้ามเลขคู่ ประมวลผลแค่เลขคี่)

## เปรียบเทียบกับชีวิตจริง (Real-world analogy)

- **for loop** เหมือน **การเดินตรวจตั๋วผู้โดยสารทีละคนบนรถบัส** — รู้แน่นอนว่ามีผู้โดยสารกี่คน (จำนวนสมาชิกใน list) เดินตรวจไปทีละคนจนครบทุกคน
- **while loop** เหมือน **การรอฝนหยุดตกก่อนออกจากบ้าน** — ไม่รู้ล่วงหน้าว่าต้องรอนานแค่ไหน แค่รอไปเรื่อยๆ ตราบใดที่เงื่อนไข "ฝนยังตกอยู่" ยังเป็นจริง
- **break** เหมือน **การหยุดค้นหากุญแจทันทีที่เจอ** — ไม่ต้องค้นกระเป๋าที่เหลือทั้งหมดต่อ เพราะเจอสิ่งที่ต้องการแล้ว
- **continue** เหมือน **การข้ามคิวเช็คช่องที่ปิดปรับปรุงในซูเปอร์มาร์เก็ต** — ข้ามช่องนั้นไปเช็คช่องถัดไปทันที โดยไม่ต้องออกจากซูเปอร์มาร์เก็ตทั้งหมด

## แผนภาพอธิบาย (Visual explanation)

### for loop — วนตามจำนวนที่รู้แน่นอน

```python
for i in range(5):     # วน i = 0, 1, 2, 3, 4 (5 รอบ)
    print(i)

┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐
│ i=0 │->│ i=1 │->│ i=2 │->│ i=3 │->│ i=4 │-> จบ (ครบ 5 รอบ)
└─────┘  └─────┘  └─────┘  └─────┘  └─────┘
```

### while loop — วนตามเงื่อนไข

```python
count = 0
while count < 3:       # ตรวจเงื่อนไขก่อนทำงานทุกรอบ
    print(count)
    count += 1          # ต้องมีบางอย่างเปลี่ยนแปลงเงื่อนไข ไม่งั้นวนไม่จบ (infinite loop)

ตรวจ count<3? True -> ทำงาน -> count+=1 -> ตรวจใหม่ -> ... -> count=3 -> False -> จบ
```

### break vs continue

```python
for i in range(10):
    if i == 5:
        break          # หยุดทั้งหมดทันทีที่ i=5 -> พิมพ์ได้แค่ 0,1,2,3,4
    print(i)

for i in range(10):
    if i % 2 == 0:
        continue       # ข้ามรอบนี้ (เลขคู่) ไปรอบถัดไปทันที
    print(i)           # พิมพ์แค่เลขคี่: 1,3,5,7,9
```

```
break:     [0][1][2][3][4] X ─── หยุดออกจาก loop ทันที
continue:  [0]skip [1]print [2]skip [3]print ... ─── ข้ามแค่รอบนี้ ไปต่อรอบถัดไป
```

### Nested Loop — ตาราง 2 มิติ

```python
for row in range(3):
    for col in range(3):
        print(f"({row},{col})", end=" ")
    print()   # ขึ้นบรรทัดใหม่หลัง loop ชั้นในจบ

# ผลลัพธ์:
# (0,0) (0,1) (0,2)
# (1,0) (1,1) (1,2)
# (2,0) (2,1) (2,2)
```

```
Outer Loop (row):  ┌───────────────────────┐
                    │ row=0                  │
                    │  Inner Loop (col):      │
                    │  col=0 -> col=1 -> col=2│ ← วนครบก่อนถึงจะไป row ถัดไป
                    ├───────────────────────┤
                    │ row=1                  │
                    │  col=0 -> col=1 -> col=2│
                    ├───────────────────────┤
                    │ row=2 ...               │
                    └───────────────────────┘
```

## ตัวอย่างโค้ด (Code example)

```python
# ===== for loop: ไล่ทุกสมาชิกใน list =====
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# ===== while loop: ทำจนกว่าเงื่อนไขจะเปลี่ยน =====
attempts = 0
password = ""
while password != "secret" and attempts < 3:
    password = input("ใส่รหัสผ่าน: ")
    attempts += 1

# ===== break: หาค่าแรกที่ตรงเงื่อนไขแล้วหยุด =====
numbers = [4, 8, 15, 16, 23, 42]
target = None
for n in numbers:
    if n > 20:
        target = n
        break          # เจอแล้วหยุดทันที ไม่ต้องวนต่อจนจบ list

# ===== continue: ข้ามค่าที่ไม่ต้องการ =====
total = 0
for n in numbers:
    if n % 2 != 0:      # ข้ามเลขคี่
        continue
    total += n           # บวกเฉพาะเลขคู่

# ===== Nested Loop: หาคู่ตัวเลขที่บวกกันได้ผลรวมตามต้องการ =====
def find_pair(nums, target_sum):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target_sum:
                return (nums[i], nums[j])
    return None

print(find_pair([2, 7, 11, 15], 9))   # (2, 7)
```

## ทำงานทีละขั้นตอน (Step-by-step execution)

1. `while password != "secret" and attempts < 3:` — เงื่อนไขถูกตรวจสอบ**ก่อน**เริ่มแต่ละรอบเสมอ (pre-condition loop) ถ้าผู้ใช้พิมพ์ผิด 3 ครั้งติดกัน เงื่อนไข `attempts < 3` จะเป็น False ทำให้ loop หยุดแม้รหัสผ่านจะยังไม่ถูกต้องก็ตาม (ป้องกันการเดารหัสไม่จำกัดครั้ง)
2. `find_pair([2, 7, 11, 15], 9)` — loop ชั้นนอก (`i`) เริ่มที่ index 0 (`nums[i]=2`) แล้ว loop ชั้นใน (`j`) เริ่มจาก `i+1` (index 1, `nums[j]=7`) ตรวจ `2+7==9` → True → `return` ทันที ค่านี้จะออกจาก**ทั้งสอง loop พร้อมกัน** เพราะ `return` จบการทำงานทั้งฟังก์ชัน ต่างจาก `break` ที่ออกแค่ loop ชั้นในสุดที่มันอยู่เท่านั้น
3. การเลือก `range(i + 1, len(nums))` แทน `range(len(nums))` ใน loop ชั้นในเป็นเทคนิคสำคัญ — ป้องกันการเทียบคู่ซ้ำ (เช่น (2,7) กับ (7,2) ถือเป็นคู่เดียวกัน) และป้องกันการเทียบตัวเลขกับตัวมันเอง (i กับ i)

## Time Complexity

- for/while loop ธรรมดา 1 ชั้น วนตามขนาดข้อมูล n: **O(n)**
- Nested loop 2 ชั้น ที่แต่ละชั้นวนตามขนาดข้อมูลเดียวกัน (เช่น `find_pair` ด้านบน): **O(n²)** — เพราะ loop ชั้นในวนซ้ำเกือบเต็มรอบสำหรับทุกๆ 1 รอบของ loop ชั้นนอก
- นี่คือรากฐานสำคัญของการวิเคราะห์ Big O ที่จะเรียนละเอียดในบทที่ 20 — จำนวนชั้นของ loop ที่ซ้อนกันมักบ่งบอกถึงระดับของ time complexity โดยตรง (1 ชั้น = O(n), 2 ชั้น = O(n²), 3 ชั้น = O(n³) เป็นต้น)

## Space Complexity

Loop เองไม่ใช้พื้นที่หน่วยความจำเพิ่มขึ้นตามจำนวนรอบ (ตัวแปรนับรอบใช้พื้นที่คงที่ O(1)) — แต่ถ้าภายใน loop มีการสร้างข้อมูลใหม่สะสมไว้ (เช่น เพิ่มสมาชิกเข้า list ทุกรอบ) พื้นที่ที่ใช้จะโตตามจำนวนรอบ O(n)

## แนวทางปฏิบัติที่ดี (Best Practices)

- ใช้ `for` เมื่อรู้จำนวนรอบหรือไล่ collection ที่มีขนาดแน่นอน ใช้ `while` เมื่อเงื่อนไขการหยุดขึ้นกับสถานการณ์ที่ไม่รู้ล่วงหน้า
- ตรวจสอบเสมอว่า `while` loop มีจุดที่ทำให้เงื่อนไขเปลี่ยนแปลงได้จริง (เช่น `attempts += 1`) ไม่งั้นจะเกิด **infinite loop**
- ใช้ `break` เพื่อออกจาก loop ทันทีเมื่อพบสิ่งที่ต้องการแล้ว แทนที่จะปล่อยให้วนจนจบโดยไม่จำเป็น (ประหยัดเวลาในกรณีที่ดีที่สุด)
- ระวัง nested loop ที่ลึกเกินไป (3+ ชั้น) เพราะ time complexity จะเพิ่มขึ้นอย่างรวดเร็ว ควรพิจารณาว่ามีอัลกอริทึมที่มีประสิทธิภาพกว่าหรือไม่ (จะเรียนในบท Algorithms)

## ข้อผิดพลาดที่พบบ่อย (Common Mistakes)

- เขียน `while` loop โดยลืมอัปเดตตัวแปรที่ใช้ในเงื่อนไข ทำให้เกิด **infinite loop** โปรแกรมค้างไม่จบ
- สับสนระหว่าง `break` กับ `continue` — ใช้ผิดที่ทำให้ loop หยุดทั้งหมดทั้งที่ต้องการแค่ข้ามรอบเดียว หรือกลับกัน
- ใน nested loop ใช้ `break` โดยคิดว่าจะออกจาก loop ทั้งหมด ทั้งที่จริง `break` ออกแค่ loop ชั้นในสุดที่มันอยู่เท่านั้น (ต้องใช้ flag ตัวแปรเพิ่ม หรือ return ถ้าอยู่ในฟังก์ชัน เพื่อออกจากทุกชั้นพร้อมกัน)
- แก้ไข list ที่กำลังวนอยู่ (เช่น ลบสมาชิกออกระหว่าง for loop) ทำให้ index เพี้ยนและข้าม/ประมวลผลสมาชิกผิดตัวโดยไม่รู้ตัว

## ข้อคิดสำคัญ (Key Takeaways)

- for loop เหมาะกับจำนวนรอบที่แน่นอนหรือไล่ collection, while loop เหมาะกับเงื่อนไขที่ไม่รู้ล่วงหน้าว่าจะจบเมื่อไหร่
- break ออกจาก loop ทั้งหมดทันที, continue ข้ามแค่รอบปัจจุบันแล้วไปรอบถัดไป
- Nested loop ใช้ประมวลผลข้อมูลหลายมิติ แต่ต้องระวังเรื่อง time complexity ที่เพิ่มขึ้นอย่างรวดเร็วตามจำนวนชั้น (O(n²), O(n³))
- while loop ต้องมีจุดที่เปลี่ยนแปลงเงื่อนไขเสมอ ไม่งั้นจะเกิด infinite loop
- จำนวนชั้นของ loop ที่ซ้อนกันสัมพันธ์โดยตรงกับ Big O ของอัลกอริทึม ซึ่งเป็นหัวใจสำคัญที่จะเรียนลึกในบท Algorithms
