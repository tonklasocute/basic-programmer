# Programming Curriculum — Beginner to Senior Backend Engineer

A full CS/software engineering curriculum, taught one chapter at a time, ordered from
easiest to hardest. Each chapter is a standalone Markdown file in this folder.

## How this works

- Chapters are numbered in learning order (prerequisites always come before what depends on them).
- Each chapter follows the same structure: Concept, Why it exists, Real-world analogy,
  Visual explanation, Code example, Step-by-step execution, Time/Space Complexity,
  Best Practices, Common Mistakes, Interview Questions, Practice Exercises, Mini Project,
  Key Takeaways.
- Say "Next" in conversation to generate the next chapter file.
